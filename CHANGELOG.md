# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-09-06

### Added

- WPF desktop interface for local cursor-movement tests.
- Interval selector, active-state indicator, countdown, and movement counter.
- P/Invoke integration with `GetCursorPos` and `SetCursorPos`.
- Display-awake request while the application is active.
- Local-only privacy model and automatic stop on window close.
